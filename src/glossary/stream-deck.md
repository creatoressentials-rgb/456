<h2>Stream Deck</h2>
<p>A <strong>Stream Deck</strong> is a programmable control device made by Elgato that uses customizable keys, and on some models dials or touch controls, to trigger actions in software and connected production tools.</p>
<p>Creators commonly use it to change scenes, mute microphones, start recordings, launch applications, post chat messages, control lights, play sound effects, and run several actions from one button.</p>

<h3>How Does a Stream Deck Work?</h3>
<p>The Stream Deck application assigns an action to each key or control. When the creator presses that control, the software sends the corresponding command to an application, operating system function, plugin, script, or supported device.</p>
<p>The keys can display custom labels, icons, status information, and different graphics after an action changes state. This makes the device more adaptable than a traditional keyboard shortcut panel.</p>

<h3>What Can a Stream Deck Control?</h3>
<ul>
  <li><strong>Streaming software:</strong> Change OBS scenes, show or hide sources, start recording, activate Studio Mode, or control a stream.</li>
  <li><strong>Audio:</strong> Mute microphones, adjust supported mixers, change monitoring, or trigger sound effects.</li>
  <li><strong>Lighting and cameras:</strong> Control compatible smart lights, creator lights, webcams, and camera applications.</li>
  <li><strong>Communication:</strong> Toggle mute, join calls, post prepared chat messages, or manage supported meeting software.</li>
  <li><strong>Editing and productivity:</strong> Run keyboard shortcuts, open folders, launch applications, execute scripts, and speed up repetitive steps.</li>
  <li><strong>Audience interactions:</strong> Trigger overlays or responses related to features such as <a href="/glossary/super-chat/">Super Chat</a> and <a href="/glossary/super-stickers/">Super Stickers</a> when supported by the creator's software.</li>
</ul>

<p>Profiles can be switched manually or configured around specific applications. Folders and pages expand the number of available actions beyond the number of physical keys.</p>

<h3>What Is a Multi Action?</h3>
<p>A Multi Action runs several commands from one control. The actions can run simultaneously or in sequence with configured delays.</p>
<p>For example, one "Go Live" button could switch to a starting scene, start the stream, wait briefly, post a message, play an intro, and unmute a microphone. Multi Actions reduce repetitive steps, but every linked application still has to be available and configured correctly.</p>

  </tbody>
</table>
<p>A Stream Deck can control a software or hardware switching workflow, but it is not itself a capture card, video switcher, audio interface, or encoder.</p>

<h3>Stream Deck vs. Macro Pad</h3>
<p>A generic macro pad sends keyboard shortcuts or programmed commands. A Stream Deck adds dynamic displays, application integrations, plugins, status feedback, folders, profiles, and multi-step actions.</p>
<p>A macro pad may be sufficient when a creator only needs a few fixed hotkeys. A Stream Deck becomes more valuable when the meaning and appearance of controls must change across apps or production states.</p>

<h3>How Creators Organize a Stream Deck</h3>
<ul>
  <li>Keep the most important live controls on the first page.</li>
  <li>Use a long press or confirmation step for actions that can end a stream or delete work.</li>
  <li>Separate scene, audio, lighting, chat, and system controls into logical groups.</li>
  <li>Use consistent icons and button locations across profiles.</li>
  <li>Create different profiles for livestreaming, recording, editing, meetings, and administrative work.</li>
  <li>Test Multi Actions after software or plugin updates.</li>
  <li>Keep mouse and keyboard access available in case an integration stops responding.</li>
</ul>

<h3>Common Stream Deck Mistakes</h3>
<ul>
  <li>Assuming the device processes or captures audio and video itself.</li>
  <li>Adding too many unlabeled pages and making controls harder to find.</li>
  <li>Using automation for a high-risk action without a confirmation or long-press safeguard.</li>
  <li>Depending on an unsupported third-party plugin for a critical production function.</li>
  <li>Building Multi Actions with timing assumptions that fail when an application opens slowly.</li>
  <li>Forgetting to back up or export important profiles and linked files.</li>
</ul>

<h3>Frequently Asked Questions</h3>
<h4>Is Stream Deck only for streamers?</h4>
<p>No. It can control editing software, meetings, music applications, smart devices, productivity workflows, and other supported tools.</p>

<h4>Does a Stream Deck replace a video switcher?</h4>
<p>No. It can command scene changes in software or control supported hardware, but it does not normally receive or process video signals.</p>

<h4>Can Stream Deck control OBS Studio?</h4>
<p>Yes. The official integration includes actions for scenes, sources, recording, streaming, Studio Mode, replay buffer functions, and other supported controls.</p>

<h4>Does Stream Deck work without plugins?</h4>
<p>It includes system actions such as hotkeys, opening applications, websites, and multimedia controls. App-specific features often require an official or third-party plugin.</p>
