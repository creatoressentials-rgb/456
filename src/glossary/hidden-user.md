<h2>Hidden User</h2>
<p>A <strong>hidden user</strong> is a YouTube viewer whose comments, live chat messages, and Community posts are prevented from being visible to other viewers on a creator's channel.</p>
<p>Hiding is a channel-wide moderation action. It is broader than deleting one comment and quieter than publicly confronting the viewer.</p>

<h3>What Happens When a User Is Hidden?</h3>
<p>YouTube says the hidden user and associated accounts have restricted activity across the channel, including:</p>
<ul>
  <li>Comments</li>
  <li>Live chat messages</li>
  <li>Community posts</li>
  <li>Creating clips from the channel's videos and live streams</li>
</ul>

<h3>Is the User Notified?</h3>
<p>No. YouTube does not notify the user that the creator hid them.</p>
<p>This silent behavior is why the action is sometimes informally described as a channel-level shadow restriction, although YouTube's official term is <strong>Hide user from channel</strong>.</p>

<h3>What Happens to Previous Comments?</h3>
<p>YouTube's current Help documentation says previous comments from the hidden user's channel are hidden from the creator's videos within 48 hours.</p>
<p>They also stop appearing in the creator's YouTube Studio Comments page.</p>

<h3>What About Associated Accounts?</h3>
<p>YouTube can apply the restriction to accounts associated with the hidden user. Current Help also warns that previous activity from associated accounts is not necessarily hidden retroactively.</p>
<p>Creators should not assume hiding one visible account finds or removes every historical message from every account a person may control.</p>

<h3>How to Hide a User From a Comment</h3>
<ol>
  <li>Find a comment the user left on the channel or a video.</li>
  <li>Select the More menu beside the comment.</li>
  <li>Select <strong>Hide user from channel</strong>.</li>
</ol>
<p>The action applies across the channel rather than only to the video where the comment appeared.</p>

<h3>How to Hide a User in YouTube Studio</h3>
<ol>
  <li>Find the viewer's channel URL.</li>
  <li>Open YouTube Studio.</li>
  <li>Select <strong>Settings</strong>.</li>
  <li>Open <strong>Community moderation</strong> and <strong>User management</strong>.</li>
  <li>Add the channel to <strong>Hidden users</strong>.</li>
  <li>Save the change.</li>
</ol>

<h3>How to Hide a User From Live Chat</h3>
<ol>
  <li>Open the viewer's live chat message.</li>
  <li>Select the moderation menu.</li>
  <li>Select <strong>Hide user from channel</strong>.</li>
</ol>
<p>YouTube does not tell the user that the action occurred.</p>

<h3>How to Hide a Community User</h3>
<p>A creator or permitted moderator can hide someone from a viewer post in the channel's Community. YouTube states that hiding from the Community applies to the whole channel.</p>

<h3>Hidden User vs. Remove Comment</h3>
<table>
  <thead><tr><th>Action</th><th>Scope</th><th>Future Activity</th></tr></thead>
  <tbody>
    <tr><td>Remove comment</td><td>One comment</td><td>User can comment again</td></tr>
    <tr><td>Hide user</td><td>User's activity across the channel</td><td>Future comments, chats, and posts are not visible</td></tr>
  </tbody>
</table>
<p>Use Remove for isolated content and Hide when the person's overall participation should no longer be visible.</p>

<h3>Hidden User vs. Report</h3>
<p>Hiding protects the creator's channel. Reporting asks YouTube to review content or behavior for a platform-policy violation.</p>
<p>For harassment, threats, scams, or serious abuse, creators may need to both hide the user and report the relevant content.</p>

<h3>Hidden User vs. Timeout</h3>
<p>A live chat timeout temporarily prevents a viewer from sending messages for a selected period. Hiding is an ongoing channel-wide restriction until the creator removes the user from the hidden list.</p>
<p>Use a timeout for temporary disruption and Hide for repeated or serious behavior.</p>

<h3>Hidden User vs. Blocked Words</h3>
<p>Blocked Words targets matching content from many viewers and allows matching comments to be reviewed in Held. Hidden User targets the person's activity across the channel.</p>
<p>YouTube says comments from hidden users do not appear in Studio, so they cannot be reviewed and individually approved from the normal Held queue.</p>

<h3>Hidden User vs. Blocking a Channel</h3>
<p>YouTube's viewer-level block controls and creator hide controls serve different purposes. The channel-owner moderation action is <strong>Hide user from channel</strong>.</p>
<p>A creator should use the channel moderation control when the goal is preventing the person's visible participation on that creator's content.</p>

<h3>Can Hidden Users Still Watch?</h3>
<p>Hiding controls visible participation; it does not generally prevent the person from watching public videos.</p>
<p>Public content remains available subject to ordinary age, geographic, account, and policy restrictions.</p>

<h3>Can Hidden Users Still Subscribe?</h3>
<p>Hiding a user is not described as automatically removing or preventing a subscription. The primary effects concern visible participation and clip creation.</p>
<p>Subscriber counts do not reveal whether a specific hidden user remains subscribed when subscriptions are private.</p>

<h3>Can Hidden Users Create Clips?</h3>
<p>No. YouTube says hidden users and associated accounts cannot create clips from the channel's videos and live streams.</p>
<p>This restriction is easy to miss because hiding is usually discussed only as a comment control.</p>

<h3>Who Can Hide Users?</h3>
<p>YouTube's current comment-moderator permissions allow:</p>
<ul>
  <li>The channel owner</li>
  <li>Managing moderators</li>
  <li>Standard moderators</li>
</ul>
<p>Managing moderators can also manage broader user and moderator settings. Give moderation roles only to trusted people because hiding affects the full channel.</p>

<h3>How to Unhide a User</h3>
<ol>
  <li>Open YouTube Studio.</li>
  <li>Select <strong>Settings</strong>.</li>
  <li>Open <strong>Community moderation</strong> and <strong>User management</strong>.</li>
  <li>Find the viewer under <strong>Hidden users</strong>.</li>
  <li>Remove the viewer from the list.</li>
  <li>Save the change.</li>
</ol>

<h3>What Happens After Unhiding?</h3>
<p>Future comments from the channel can become visible again under the normal moderation settings.</p>
<p>Previous comments that were hidden do not automatically return. Unhiding is forward-looking rather than a restoration of the user's old comment history.</p>

<h3>Can Hidden Comments Be Reviewed?</h3>
<p>No. YouTube says comments from hidden users do not appear in YouTube Studio.</p>
<p>This is an important difference from blocked words, blocked links, and Basic or Strict moderation, which send comments to Held for possible approval.</p>

<h3>When to Hide a User</h3>
<ul>
  <li>Repeated harassment</li>
  <li>Persistent spam</li>
  <li>Impersonation</li>
  <li>Scams</li>
  <li>Repeated evasion after comment removal</li>
  <li>Targeted abuse of other viewers</li>
  <li>Deliberate disruption across comments and live streams</li>
  <li>Posting personal information</li>
</ul>

<h3>When Not to Hide a User</h3>
<p>Hiding may be excessive for:</p>
<ul>
  <li>One respectful disagreement</li>
  <li>A factual mistake made in good faith</li>
  <li>An off-topic comment that can simply be removed</li>
  <li>A viewer who does not understand a channel guideline</li>
  <li>A first-time minor live chat disruption suited to a timeout</li>
</ul>

<h3>Documenting Moderation Decisions</h3>
<p>For channels with a team, keep a private moderation log containing:</p>
<ul>
  <li>The user or channel URL</li>
  <li>The reason for hiding</li>
  <li>Relevant screenshots or message links</li>
  <li>The moderator who acted</li>
  <li>The date</li>
  <li>Whether the content was reported</li>
  <li>Any planned review date</li>
</ul>
<p>Do not publish personal information or use the log to organize harassment.</p>

<h3>Hidden Users and Members</h3>
<p>Paying for a <a href="/glossary/channel-memberships/">Channel Membership</a> does not exempt someone from moderation. A member who violates rules can be hidden like another user.</p>
<p>Membership billing and moderation are separate systems. Creators should review any separate cancellation or refund implications without allowing payment to override safety.</p>

<h3>Hidden Users and Live Chat Replay</h3>
<p>Messages removed or hidden during a live event may not remain in <a href="/glossary/live-chat-replay/">Live Chat Replay</a>. The replay represents the moderated public chat rather than every attempted message.</p>

<h3>Hidden Users and Pinned or Hearted Comments</h3>
<p>If a previously visible comment was pinned or hearted, hiding the user removes that comment from public visibility. Engagement signals do not override the hidden-user restriction.</p>

<h3>Can the User Appeal to the Creator?</h3>
<p>YouTube does not provide a formal channel-level appeal system for being hidden. The creator controls the hidden-user list.</p>
<p>A creator can establish an external contact or review policy, but should not invite abusive users to continue harassment through another platform.</p>

<h3>Common Hidden-User Mistakes</h3>
<ul>
  <li>Using Hide for one harmless comment.</li>
  <li>Assuming the user is notified.</li>
  <li>Expecting previous comments to reappear after unhiding.</li>
  <li>Thinking the action prevents public video viewing.</li>
  <li>Forgetting the clip-creation restriction.</li>
  <li>Looking for hidden comments in the Held tab.</li>
  <li>Assuming every historical associated-account message disappears.</li>
  <li>Giving moderator access without a documented policy.</li>
</ul>

<h3>Frequently Asked Questions</h3>
<h4>Does YouTube tell a user they were hidden?</h4>
<p>No. YouTube says the user is not notified.</p>

<h4>How quickly are old comments hidden?</h4>
<p>YouTube's current Help documentation says previous comments from that channel are hidden within 48 hours.</p>

<h4>Do old comments come back after unhiding?</h4>
<p>No. Future comments can appear, but previously hidden comments remain hidden.</p>

<h4>Can a hidden user still watch public videos?</h4>
<p>Generally yes. Hiding restricts visible participation and clip creation rather than public playback.</p>
