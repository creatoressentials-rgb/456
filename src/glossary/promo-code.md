<h2>Promo Code</h2>
<p>A <strong>promo code</strong> is a word, phrase, or alphanumeric code that a customer enters or activates to receive a merchant-defined offer.</p>
<p>Common offers include:</p>
<ul>
<li>Percentage discount</li>
<li>Fixed-dollar discount</li>
<li>Free shipping</li>
<li>Buy one, get one</li>
<li>Free gift</li>
<li>Trial extension</li>
<li>Bundle price</li>
<li>Creator-specific offer</li>
</ul>
<p>In creator campaigns, a unique code can also help track sales associated with a creator or piece of content.</p>

<p>One code can perform several roles. A creator code may provide a discount and trigger <a href="/glossary/affiliate-commission">affiliate commission</a>.</p>
<h3>How creator promo codes work</h3>
<ol>
<li>The merchant creates a unique code.</li>
<li>The campaign defines the offer and eligibility.</li>
<li>The creator shares the code with clear disclosure.</li>
<li>A customer enters it at checkout.</li>
<li>The commerce system validates the conditions.</li>
<li>The discount is applied.</li>
<li>The order is recorded in code-level reporting.</li>
<li>Returns, cancellations, and fraud are reconciled.</li>
<li>Commission or performance bonuses are calculated under the contract.</li>
</ol>
<h3>Promo code attribution</h3>
<p>A creator-specific code can capture customers who:</p>
<ul>
<li>Remember the code without clicking</li>
<li>Watch on television and purchase on a phone</li>
<li>Buy later through another device</li>
<li>Hear the code in a podcast or livestream</li>
</ul>
<p>However, code attribution can overstate or understate influence.</p>
<p>It can overstate when:</p>
<ul>
<li>Coupon sites publish the code</li>
<li>Existing customers search for discounts</li>
<li>Another creator influenced the sale</li>
<li>Customer service manually applies it</li>
</ul>
<p>It can understate when:</p>
<ul>
<li>The customer forgets the code</li>
<li>Another discount is better</li>
<li>The code cannot be combined</li>
<li>The customer buys through a retailer</li>
<li>The creator influenced a later full-price purchase</li>
</ul>
<p>Promo-code reporting is useful evidence, not perfect causal attribution.</p>

<p>Using both can improve coverage, but the contract must define which source receives credit when they conflict.</p>

<h3>Promo code disclosure</h3>
<p>A discount does not tell viewers that the creator receives money, free products, or another benefit.</p>
<p>Clear language can include:</p>
<ul>
<li>“Use ROB10 for 10% off. I earn a commission on qualifying purchases.”</li>
<li>“This video is sponsored by the brand, and my code saves you 15%.”</li>
<li>“I received this product for free and may earn commission from my code.”</li>
</ul>
<p>The FTC says disclosures should be clear, conspicuous, and placed with the endorsement itself.</p>

<ul>

<li>Returns</li>

<h3>Promo code economics</h3>
<p>A campaign can produce strong sales but weak profit when the brand pays:</p>
<ul>
<li>Product cost</li>
<li>Discount</li>
<li>Creator commission</li>
<li><a href="/glossary/sponsorship/">Sponsorship</a> fee</li>
<li>Paid media</li>
<li>Shipping subsidy</li>
<li>Processing fees</li>
<li>Returns</li>
</ul>
<p>Evaluate <a href="/glossary/return-on-ad-spend">return on ad spend</a>, contribution margin, and customer lifetime value rather than code revenue alone.</p>
<h3>Code leakage and fraud</h3>
<p>Common issues include:</p>
<ul>
<li>Coupon websites indexing the code</li>
<li>Browser extensions applying it automatically</li>
<li>Creators sharing private codes</li>
<li>Self-referrals</li>
<li>Multiple customer accounts</li>
<li>Employees using the code</li>
<li>Bots testing codes</li>
<li>Code use after campaign end</li>
<li>Unauthorized paid-search ads</li>
</ul>
<p>Controls can include unique links, customer eligibility, redemption limits, short campaign windows, and source analysis.</p>
<h3>Promo code mistakes</h3>
<ul>
<li>Choosing a difficult code</li>
<li>Using ambiguous characters</li>
<li>Forgetting the expiration time zone</li>
<li>Not testing checkout</li>
<li>Offering a code weaker than the site's public sale</li>
<li>Failing to disclose commission</li>
<li>Treating every code sale as incremental</li>
<li>Paying commission before the return period</li>
<li>Not defining link-and-code conflicts</li>
<li>Leaving an old code active indefinitely</li>
</ul>

<h3>Frequently asked questions</h3>
<h4>Is a promo code the same as an affiliate code?</h4>
<p>Not always. A promo code provides an offer. It becomes an affiliate code when the program uses it to attribute commission.</p>
<h4>Can promo codes track creator sales?</h4>
<p>Yes, but they miss sales without the code and can credit sales from coupon sites or other sources.</p>
<h4>Does a promo code replace <a href="/glossary/sponsorship-disclosure/">sponsorship disclosure</a>?</h4>
<p>No. Viewers still need to understand the creator's material relationship with the brand.</p>
<h4>Should commission be based on sales before or after the discount?</h4>
<p>The agreement should define commissionable revenue, including discounts, taxes, shipping, refunds, and returns.</p>
